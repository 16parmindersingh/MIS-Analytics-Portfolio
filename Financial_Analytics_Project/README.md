# Financial Analytics Project 📊📈

## Project Overview
This project delivers a robust Excel-based analytics suite designed for an MIS Analyst role, analyzing financial performance, geographic trends, sales processes, and project workflows. Built entirely in Excel with no macros or VBA, it utilizes dynamic charts, pivot tables, and slicers to provide interactive, actionable insights for management reporting. The objective is to support data-driven decision-making, aligning with MIS responsibilities such as performance tracking, trend analysis, and strategic reporting.

This project highlights my expertise in **data analysis**, **MIS reporting**, and **business intelligence visualization**, making it a strong showcase for MIS Analyst opportunities.

---

## Dataset Description
The dataset, stored in `Datasets.xlsx`, contains raw data fueling the analysis in `Financial_Analytics_Overview.xlsx`. It encompasses key MIS metrics across four dashboards:

- **Income Sources**: Detailed breakdown of revenue streams, marketing effectiveness, and goal tracking.
- **Geographically**: Profit distribution and tax insights by region for regional performance analysis.
- **Sales Process**: Sales pipeline stages, targets, and channel performance for process optimization.
- **Project Status**: Key performance indicators (KPIs) and project progress for operational oversight.

### Data Insights
- Supports multi-year analysis (2020–2025) with dynamic yearly slicer filtering, ideal for trend reporting.
- Reveals critical patterns in income sources, regional profitability, sales efficiency, and project KPIs.
- Visualizations underscore dominant revenue channels and geographic priorities for MIS focus.

## What I Did in This Project
This project follows a structured MIS workflow, focusing on data preparation, visualization, and reporting. Here’s a detailed breakdown:

### 1. Data Loading and Exploration
- Imported raw data into Excel and explored it using filters and pivot tables to identify MIS-relevant metrics.
- Analyzed income, geographic, sales, and project data for comprehensive reporting.

### 2. Data Cleaning
- Ensured data integrity by removing duplicates and inconsistencies, preparing it for MIS dashboards.
- Structured data for dynamic slicer-based reporting across years.

### 3. Data Visualization
- Developed an interactive web chart and doughnut chart for Income Sources tracking.
- Created a dynamic map chart for Geographically and a sales pipeline diagram for Sales Process.
- Designed a KPI layout for Project Status with bar and line charts.
- Implemented yearly slicer filtering for real-time MIS updates.

### 4. Reporting
- Captured static dashboard views in PNG files (`Dashboard 1 - Income Sources.PNG`, etc.).
- Recorded a demo video (`Financial_Analytics_Demo.mp4`) to present MIS findings effectively.

### Key Output
The `Financial_Analytics_Overview.xlsx` file integrates all dashboards, with PNGs and the video serving as MIS deliverables.
